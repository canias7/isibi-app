## The change

- **The tool** (`builder/site-add.mjs`): the add step's job tool uses
  `ADD_JOB_ITEM`, the build's `JOB_ITEM` plus an optional `function` whose
  shape is `FUNCTION_ITEM` (the `function` answer's own item). The build's
  `design_schema` keeps `JOB_ITEM` unchanged.
- **The rule** (`ADDS.job.add.yours`, g4's wording replaced): the job names a
  function on the list a job may run, or, when none fits, writes it in the
  same answer (`internal: true`, `fn` set to its name); never a name that is
  neither, and never a name the site already lists.
- **The cleaner** (`cleanAdd("job")`): when any item carries `function`, each
  one goes through `cleanAdd("function", [f], site)` (the same cleaner, no
  second path), must come back `internal: true` (`job-fn-public`), must not
  reuse a listed name or one declared earlier in the answer
  (`job-fn-exists`), and must match the job's `fn` (`no-job-fn`). Kept ones
  join `jobFns` before the jobs are cleaned; the result carries them as
  `functions` (only those a kept job runs). A refused function refuses its
  job, named in `skipped` with the function's own reason. Two new refusal
  sentences in `addRefusal`.
- **The route** (`worker.js`, add-on designer loop):
  - a job answer's `functions` are pushed as one more `function` answer before
    the job, so `foldAdds`, the schema merge and apply, the draft hold, the
    reply (`functions`, `kinds`), `judgeItems` and the Publish path's
    dead-function check (`deadNewFunctions`/`jobsWithoutDead`, which read the
    spec's functions) treat them as any designed function;
  - `aFoldInto` folds a job list's own functions (a `WeakMap` keyed by the
    cleaned list, set on the official and the early path) before the job, so
    every later designer and the proposal see them;
  - the property audit strips the job's `function` key and audits the
    declared functions as the `function` tier; the job's audit context
    includes them. **Found by the sweep**: without that, the job was audited
    against a proposal lacking its function and recorded `unbuilt`
    (`coverage.unbuilt: {job: ["weekly_count"]}`), counted as a failed kind.
