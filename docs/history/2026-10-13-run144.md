## 5. The one failed check: a false failure, fixed offline (no re-run)

`/bake-list still says everything it said` failed with
`lost: ["join the weekly bake list"]`.

**Cause.** The section check compares every text run on the page before and
after. It never excused the heading the Edit was asked to change, and the
page-by-page check that does excuse an asked heading (`headingOnly`) skips
any page that gained a section. This was the first scenario with both changes
on one page. The product did nothing wrong: the run was the heading's asked
change.

**Fix** (`72e82266`; `scripts/canary-requests.mjs`, `headingSwapped`). On a page that
also has an expected heading change, one run that is exactly the heading's
old words, replaced by one run that is exactly its new words, is the Edit's
change:
- it is neither lost nor text of the added section;
- anything else lost still fails;
- a heading changed to other words, or asked for on another page, excuses
  nothing.

**Tests** (`test/canary-section-heading.test.mjs`, 3):
- **SH 1:** run 144's shape passes every check.
- **SH 2:** the controls: other words lost beside the swap still fail; a
  heading changed to unasked words is still lost; a heading on another page
  excuses nothing.
- **SH 3:** the helper is exact, one for one, and does not mutate its inputs.

**Red check:** with the excuse disabled, SH 1 fails exactly as run 144 did.
