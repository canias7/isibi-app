# Audit finding 79 (A01-5), 2026-10-22

From `docs/audits/2026-10-17-builder-audit.md`, on branch `audit-79` (from
`codex-work-into-claude`). Offline; nothing spent; not merged or deployed.

- **Finding (re-confirmed real today).** Every first build writes the building
  stand-in to `sites/<slug>/index.html` before generation
  (`publishPlaceholder(..., { building: true })`). Its sentence ends "If it's
  still here in a few minutes, send your message again and I'll pick it up."
  `clearPlaceholder` ran only on a live upload (`if (!preview)` in
  `uploadScriptOnce`). Under `DRAFT_FIRST` a first build saves a draft and
  uploads only the preview script, so the live address kept that sentence
  until Publish, and a customer who followed it paid for another build.
- **Fix** (`worker.js`). The sentence is now the constant
  `PLACEHOLDER_BUILDING`. A new `draftPlaceholder(env, slug)` runs as the
  `else` of the clear, after the upload's refusals, when a preview script has
  landed: if `index.html` carries the stand-in mark and the building
  sentence, that sentence is replaced by `PLACEHOLDER_DRAFT`: "This site
  isn't published yet. Its owner is getting it ready, so check back soon."
  The stand-in stays (visitors never see the unpublished draft and the
  address does not 404); the mark stays, so the first real publish still
  clears it. A real page, the failure wording or an empty key is left alone,
  and it never throws.
- **Tests** (`test/site-placeholder.test.mjs`): three new cases (driven with
  the real writer: reworded, mark and title kept, later clear works; only
  the building stand-in reworded, no-throw; wiring: the one call is the
  preview branch of the clear, after `if (!r.ok)`); the one-constant guard's
  count of `PLACEHOLDER_META` moved 3 → 4. Red check on the old `worker.js`:
  4 of 10 fail (the 3 new ones and the count guard).
- **Not done through the full build path**: no harness drives a DRAFT_FIRST
  first build to the preview upload offline; the driven unit plus the wiring
  guard cover it.
- **Sweep** (scratch script, 9 mutants on `worker.js`): 8 of 8 killed (call
  dropped, called on live too, each guard dropped, no swap, a resend in the
  draft wording, delete instead of reword, catch removed); the comment-only
  control survived.
