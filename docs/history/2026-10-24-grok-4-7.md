  the providers row say "Grok 4.7".
- `builder/model-xai.mjs`: comment only (efforts confirmed for 4.7).

version, so a saved choice moves to 4.7 by itself. A stored request or usage
object naming `grok-4.6` still sizes and prices (both rows kept), and is
still sent to xAI (`isXaiModel` matches the `grok-` prefix).

Tests that pass `grok-4.6` as an explicit xAI model name are left as they
are: they test the xAI path, not the default, and 4.6 stays a valid id.
