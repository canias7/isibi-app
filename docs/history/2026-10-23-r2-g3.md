## Options for the owner

**A33-7, the canonical host on a custom domain.** Today every canonical and
og:url names `<name>.gofarther.app`, while the sitemap served on the custom
domain lists the custom domain.
1. The verified custom domain wins: `publicUrlFor` prefers it, and connecting
   or removing a domain re-patches the live sidecar. Search engines index the
   owner's domain. **Recommended.**
2. Derive the canonical from the request host when it is the site's own
   domain (in the site script). No sidecar change, but both hosts call
   themselves canonical.
3. Keep `.gofarther.app` canonical and make the custom domain's sitemap list
   `.gofarther.app` addresses too (consistent, but the owner's domain is never
   the indexed one).

**A34-2, button labels under 4.5:1 on 21 shortlisted themes.**
1. Fit each theme's accent (step its lightness until the label clears 4.5:1),
   the way state colours are fitted, and run the pair check over every
   registry theme. Buttons on those themes change shade slightly.
   **Recommended.**
2. Drop the failing themes from the shortlist (no colour changes; fewer
   themes to choose from).
3. Keep the themes and record 3:1 as the bar (not WCAG AA for 14px labels).

**A34-3, the contrast probe skips page text on translucent themes (467 of
500).**
1. Measure page text on a translucent theme root against the theme's paper
   (or its worst ground), and count `scanned` only after a background was
   resolved. More real findings, and possibly new false alarms on backdrop
   themes; findings reach replies. **Recommended**, behind a check of a few
   live sites first.
2. Only correct the `scanned` count, so a page whose text was all skipped no
   longer reads as "looked and clean".
3. Leave it as is and record the gap.
