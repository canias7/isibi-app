## A03-6 — renaming the business missed the site's own components

- **Finding (re-verified).** The look step's rename (`renamePages`) was handed
  `qrCut ? qrCut.pages : eSrc`, the pages only. On a site split into bands the
  visible copy lives in `-parts/` components, so the hero and footer kept the
  old name; the publish sent no renamed parts, and the reply's `renamed`
  counted pages only. Driven through the route: the hero still read the old
  name after a reply of `ok`.
- **Fix** (`worker.js`, look rung). When the brand moves, the site's
  components are read before the look is written (`editParts`); an
  unreadable store refuses with `parts-unreadable`, cost 0, nothing stored or
  published (the text rung's rule). The rename runs over
  `editableFiles(pages, parts)` (the parts a QR removal already read, when
  one did), the result is split back with `splitEditable`, and both halves
  are published. `renamed` counts the files whose prose changed. The same
  `renamePages` (prose only, via `extractText`) does the rewriting, so link
  addresses and code are untouched.
- **Tests** (`test/look-rename-parts.test.mjs`, 8 cases, sync and queued,
  through the real edit route): components renamed, prose only, untouched
  component kept, publish carries the renamed parts, count 2; unreadable
  store refused before writing; a site with no components still renames its
  pages (control); a rename beside a QR removal renames the components that
  removal read. One spelling guard in `test/site-apply.test.mjs` pinned the
  old call and now pins the new one.
- **Red check.** 4 of the first 6 fail on the old code (the 2 controls pass).
- **Sweep.** 5 of 5 mutants killed (pages only; no refusal; parts not
  published; no read; the QR removal's parts ignored, killed after the
  eighth case was added); the comment-only control survived.
- **Full suite** (`node --test "test/*.test.mjs"`, before the guard update):
  11,840 tests, 11,834 pass, 3 fail, 3 skipped. The fails: the spelling guard
  (updated); `no-generated-deps` (caused by the temporary `node_modules`
  symlink this run needs; removed before commit); `media-verify`'s browser
  case, which passes run alone (load-sensitive, unrelated).
