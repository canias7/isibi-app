# Working in this app

This project was generated by isibi. It is a Vite + React + TypeScript app using Tailwind v4
and TanStack Router.

## Layout

- `src/routes/` — file-based routing, one file per page. See `src/routes/README.md` for the
  naming conventions.
- `src/components/ui/` — shadcn/ui components. Owned by this repo; edit them freely.
- `src/styles.css` — the design system. The `@theme` block at the top holds this app's own
  tokens; everything below it is the shared shadcn base.
- `src/lib/utils.ts` — the `cn` class-merging helper.

## Styling

Use the semantic tokens, not raw colours: `bg-background`, `text-foreground`, `bg-card`,
`text-muted-foreground`, `border-border`, `bg-primary`. They are defined for light and dark in
`src/styles.css`, so a raw `bg-slate-900` will break dark mode.

To add a colour: define it in `:root` and `.dark`, then register it in `@theme inline` as
`--color-<name>: var(--<name>)`. All colours use oklch.

## Generated files

`src/routeTree.gen.ts` is produced by `tsr generate` before each build. Never edit it.
