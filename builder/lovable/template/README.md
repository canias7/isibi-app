# Your Go Farther project

This app was built with [Go Farther](https://gofarther.dev). The code is yours — clone it, run it, change it.

## Development

You need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

| Command           | What it does                                                |
| ----------------- | ----------------------------------------------------------- |
| `npm run dev`     | Generates the route tree, then starts Vite on a local port. |
| `npm run build`   | Generates the route tree, then builds to `dist/`.           |
| `npm run preview` | Serves the built `dist/` so you can check the real bundle.  |
| `npm run lint`    | ESLint over `**/*.{ts,tsx}`.                                |
| `npm run format`  | Prettier over the whole project.                            |

## How it fits together

- **Routing is file-based.** A file at `src/routes/book.tsx` becomes `/book`. `src/routeTree.gen.ts`
  is generated by `tsr generate` and is not committed — never edit or import it directly.
- **`src/routes/__root.tsx` is the shell**: header, nav, footer, site-wide meta and the webfonts.
- **The database is declared in `gofarther.schema.json`**, and `src/integrations/db/types.ts` is
  generated from it. Read and write through `src/integrations/db/client.ts`, never with a bare
  `fetch` — the client attaches auth and keeps row types honest.
- **`src/components/ui/` is the component library.** Import from it rather than rebuilding a button.
- **Styling is Tailwind v4**, configured in CSS. The palette lives in `src/styles.css` as tokens;
  change a token there and it changes everywhere.

`AGENTS.md` is the same map written for a coding agent. Point yours at it.
